# analyze_google_drive_duplicates
Google雲端硬碟內重複檔案檢查（Google Apps Script，綁定在試算表上執行）

## 安裝
1. 開一個新的 Google 試算表 →「擴充功能」→「Apps Script」。
2. 把 `main` 的內容貼到 `程式碼.gs`。
3. 「專案設定」勾選「在編輯器中顯示 appsscript.json」，用本專案的 `appsscript.json` 取代；
   或在左側「服務」手動加入 **Drive API（v3，識別碼 `Drive`）**。
4. 重新整理試算表，選單會出現「🚀 雲端清理工具V7」。

## 使用
- **▶️ 啟動一鍵自動化掃描**：清除上次結果後開始，背景每 5 分鐘自動接續，完成後寄 Email。
- **⏯️ 手動接續一次**：不等排程，立刻接著跑；排程不見時會自動補建。
- **🔍 檢查執行狀態**：顯示目前階段、排程數量、最後一次執行與最後錯誤，用來判斷為什麼停住。
- **🧹 停止並重置進度**：停止排程並清除所有暫存與結果。
- 進度看 `StatusPanel` 分頁（「最後一次執行」那一列會記錄每次排程的結果），結果在 `重複檔案清單` 分頁。

## 執行流程
每個階段都能中斷，由排程（預設每 5 分鐘）從同一個進度接續：

1. **掃描**：Drive API 分頁列出所有檔案與資料夾，寫進 `FileIndex`／`FolderIndex`。
2. **依 MD5 排序 → 分批比對內容**：在試算表端排序後，每次讀 `ANALYZE_CHUNK`（預設 1 萬）列，
   而且只在群組邊界切開，同一組不會被拆到兩批。
3. **依檔名排序 → 分批比對檔名副本**：做法同上，已列入 MD5 組的檔案不重複列出。
4. **整理結果**：依可釋放空間排序、重新編號，寄 Email。

檔案數量再多也不會一次全部讀進記憶體；中途當掉時，會清掉那一批已寫一半的結果再重做，不會重複。
上限是試算表的 1,000 萬格：`FileIndex` 有 10 欄，約可容納 100 萬個檔案。

## 判定方式
| 判定方式 | 說明 | 建議 |
|---|---|---|
| 內容相同 (MD5) | MD5 一樣，不限資料夾、不限檔名 | 每組保留一個，其餘「可刪除」 |
| 檔名副本 | 同資料夾、同類型，去掉「 (1)」「的副本」「Copy of」後檔名相同 | 請人工確認 |
| 檔名副本（Google 文件，無法比對內容） | Google 文件／試算表／簡報沒有 MD5，只能看檔名 | 請人工確認 |
| 檔名相同，但內容不同 | 檔名像副本但 MD5 不同，可能是不同版本 | 請人工確認 |

每組會挑一個「保留」：優先挑檔名本身就是原始檔名的，其次挑最早建立的。
0 位元組的檔案、捷徑、垃圾桶裡的項目不列入。

## 設定（`main` 最上方 `CONFIG`）
- `ONLY_MY_FILES`：預設 `true`，只掃自己擁有的檔案；改 `false` 會包含別人分享的檔案。
- `TRIGGER_MINUTES`：接續排程間隔（1、5、10、15、30）。
- `MAX_ERRORS`：連續錯誤幾次才停止任務（暫時性錯誤會自動重試）。
- `ANALYZE_CHUNK`：比對階段每批讀取的列數。
